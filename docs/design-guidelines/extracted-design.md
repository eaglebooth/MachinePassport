# MachinePassport visual direction

Source asset: user-provided MachinePassport logo, inspected 2026-09-01.

## Extracted palette

- Black-blue void: `#020817`
- Deep navy panel: `#071B46`
- Cobalt structure: `#0754D8`
- Electric blue: `#0B86FF`
- Cyan instrumentation: `#20E5F5`
- Cold white: `#EFF8FF`
- Verified mint: `#19F2A2`

## Shape and material language

- Rounded industrial housings, illuminated edge rails, blueprint lines.
- Dense instrumentation rather than pale document cards.
- Passport identity block paired with a maintenance timeline.
- Thin cyan rules, square telemetry labels, circular machine gauges.

## Typography

- Display: `Oxanium`, squared technical letterforms.
- Body: `Sora`, compact and readable.
- Telemetry: `IBM Plex Mono`.

## Layout

- Landing: asymmetric split with large supplied logo and operational copy.
- Console: left vertical sequence rail, central current action, right persistent passport readback.
- One document scrollbar; no full-height nested scrolling.
- Long addresses and hashes wrap safely.

## Motion

- Slow radar sweep and pulse only in decorative areas.
- Transaction state uses short status transitions; no delayed primary actions.

## Explicit anti-clone constraints

- No cream background.
- No two-column stack of identical white forms.
- No ClausePilot typography, rounded lime pills, status rail, or card layout.
- No reuse of ClausePilot CSS or component files.
